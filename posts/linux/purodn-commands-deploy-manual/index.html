purodn / purodncode 快捷命令部署手册

内部运维手册（永不发布）：Hugo 站点两个快捷命令（发布线上 / 备份源码）的完整脚本、部署步骤与新机器重装指引。

⚠️ 本文是内部运维手册，draft = true 永不发布。用于新机器人/新机器重装时照做。

最后核验：2026-08-06（purodn、purodncode 均已加固并实测跑通）

⚠️⚠️ 2026-08-06 新增重大坑：hugo server 必须加 --renderToMemory！ Hugo 0.131 的 hugo server 默认写盘到 public/（含草稿），长跑期间会把所有 draft=true 文章（含真实凭据）渲染进 public/ 发布工作树，git add -A 一推就泄露。启动命令必须是：

hugo server -D --bind 0.0.0.0 --port 1313 --baseURL http://0.0.0.0:1313 --disableFastRender --renderToMemory

日志出现 “Serving pages from memory” 才算对。若已污染：停 server → 对查删 public/ 草稿残留 → git -C public clean -fd → git -C public checkout -- . 恢复。

一、这两个命令是干什么的

命令 作用 目标仓库 是否含草稿
purodn 发布网站到线上 public/（GitHub Pages） ❌ 不含（会清理草稿残留）
purodncode 备份源码 源码仓库（私有） ✅ 全量含草稿

本站架构双仓库分离：

  • 源码仓库：git@github.com:hanigege/purodn.tk-source-code.git（私有，存 Markdown 原文、草稿、assets、模板、脚本）
  • 发布仓库：git@github.com:hanigege/purodn.tk.git（公开，GitHub Pages 部署源）

二、依赖环境（新机器先装好）

# 1. Hugo（0.131+，extended 版）
# Ubuntu/Debian:
sudo apt install hugo   # 或从 https://github.com/gohugoio/hugo/releases 下载

# 2. git、lsof、rsync（后两个脚本用）
sudo apt install git lsof

# 3. SSH key 已配置（能免密访问 github.com）
ssh -T git@github.com   # 应输出 Hi <user>! You've successfully authenticated

# 4. 目录结构
mkdir -p ~/codex/hugo/scripts
# 源码仓库 clone 到这里：
git clone git@github.com:hanigege/purodn.tk-source-code.git ~/codex/hugo
cd ~/codex/hugo
# 发布仓库 clone 到 public/：
git clone git@github.com:hanigege/purodn.tk.git public

三、完整脚本（直接保存）

两个脚本放在 /home/hermesuser/codex/hugo/scripts/，执行权限 chmod +x。

3.1 purodn（发布线上）

#!/bin/sh
set -eu

# ============================================================
# purodn — Hugo 一键发布（安全版）
# 2026-08-06 加固：草稿检查 / pull --autostash / SSH wrapper
# ============================================================

SITE_DIR="$HOME/codex/hugo"
SITE_DIR="$(realpath "$SITE_DIR")"
PUBLIC_DIR="$SITE_DIR/public"
SSH_WRAPPER="$HOME/.hermes/scripts/git-ssh-wrapper.sh"

cd "$SITE_DIR"

if ! command -v hugo >/dev/null 2>&1; then
  echo "Error: hugo command not found." >&2
  exit 1
fi

if [ ! -d "$PUBLIC_DIR/.git" ]; then
  echo "Error: $PUBLIC_DIR is not a Git repository." >&2
  exit 1
fi

# ① 发布前拉取最新发布仓库（--autostash 防未提交变更报错）
echo "Pulling latest public/ ..."
if [ -x "$SSH_WRAPPER" ]; then
  GIT_SSH_COMMAND="$SSH_WRAPPER" git -C "$PUBLIC_DIR" pull --rebase --autostash origin main
else
  git -C "$PUBLIC_DIR" pull --rebase --autostash origin main
fi

# ② 草稿安全检查（防草稿旧 HTML 被推上线）
echo "Checking draft leftovers..."
for f in $(grep -rl 'draft = true' content/posts/ --include='index.md' 2>/dev/null); do
  # 2a. 草稿文章页
  dir=$(dirname "$f" | sed 's|content/||')
  if [ -d "$PUBLIC_DIR/$dir" ]; then
    echo "⚠️  draft leftover: public/$dir"
    rm -rf "$PUBLIC_DIR/$dir"
  fi
  # 2b. 草稿文章的 tags：检查对应 tag 页
  draft_tags=$(grep -E '^tags\s*=\s*\[' "$f" | sed -E "s/.*\[(.*)\].*/\1/" | tr ',' '\n' | tr -d " '")
  draft_slug=$(basename "$(dirname "$f")")
  for tag in $draft_tags; do
    others=$(grep -rl "$tag" content/posts/ --include='index.md' 2>/dev/null | grep -v "$f" || true)
    has_published=0
    for o in $others; do
      if ! grep -q 'draft = true' "$o"; then
        has_published=1
        break
      fi
    done
    # 2b-1. 草稿专属 tag（无已发布文章）→ 整目录删
    if [ "$has_published" = "0" ] && [ -d "$PUBLIC_DIR/tags/$tag" ]; then
      echo "⚠️  draft tag leftover: public/tags/$tag"
      rm -rf "$PUBLIC_DIR/tags/$tag"
    fi
    # 2b-2. 共享 tag 页内残留草稿链接 → 删页重建
    if [ "$has_published" = "1" ] && [ -d "$PUBLIC_DIR/tags/$tag" ]; then
      if grep -rq "$draft_slug" "$PUBLIC_DIR/tags/$tag/"; then
        echo "⚠️  draft link in shared tag: public/tags/$tag (rebuilding)"
        rm -rf "$PUBLIC_DIR/tags/$tag"
      fi
    fi
  done
done

# ③ 正式构建
echo "Building Hugo site..."
hugo --minify --gc

# ④ 构建后复查：草稿不应出现在 public/ 输出中
echo "Verifying no drafts in output..."
for f in $(grep -rl 'draft = true' content/posts/ --include='index.md' 2>/dev/null); do
  dir=$(dirname "$f" | sed 's|content/||')
  if [ -d "$PUBLIC_DIR/$dir" ]; then
    echo "Error: draft still present after build: public/$dir" >&2
    exit 1
  fi
  draft_tags=$(grep -E '^tags\s*=\s*\[' "$f" | sed -E "s/.*\[(.*)\].*/\1/" | tr ',' '\n' | tr -d " '")
  draft_slug=$(basename "$(dirname "$f")")
  for tag in $draft_tags; do
    if [ -d "$PUBLIC_DIR/tags/$tag" ]; then
      if grep -rq "$draft_slug" "$PUBLIC_DIR/tags/$tag/"; then
        echo "Error: draft link in tag after build: public/tags/$tag" >&2
        exit 1
      fi
    fi
  done
done

rm -rf "$SITE_DIR/resources" "$SITE_DIR/.hugo_build.lock" "$SITE_DIR/.DS_Store"

cd "$PUBLIC_DIR"

if [ -z "$(git status --short)" ]; then
  echo "No publish changes."
  exit 0
fi

echo "Publishing public/ to origin/main..."
git add -A
git commit -m "Publish site updates"

# ⑤ SSH wrapper 推送（OpenSSH 9.9 兼容）
if [ -x "$SSH_WRAPPER" ]; then
  GIT_SSH_COMMAND="$SSH_WRAPPER" git push origin main
else
  git push origin main
fi

echo "Published successfully."
echo "Deploy may take 30-90s. Verify:"
echo "  curl -s -m 5 -H 'Cache-Control: no-cache' https://purodn.tk/posts/<分类>/<slug>/ | grep -c '<正文独有短语>'"

3.2 purodncode（备份源码，含草稿）

#!/bin/sh
set -eu

SITE_DIR="$HOME/codex/hugo"
SITE_DIR="$(realpath "$SITE_DIR")"
SOURCE_REMOTE="git@github.com:hanigege/purodn.tk-source-code.git"
COMMIT_MESSAGE="${1:-Backup source updates}"
SSH_WRAPPER="$HOME/.hermes/scripts/git-ssh-wrapper.sh"

cd "$SITE_DIR"

if ! command -v hugo >/dev/null 2>&1; then
  echo "Error: hugo command not found." >&2
  exit 1
fi

if [ ! -d "$SITE_DIR/.git" ]; then
  echo "Error: $SITE_DIR is not a Git repository." >&2
  exit 1
fi

origin_url="$(git remote get-url origin)"
if [ "$origin_url" != "$SOURCE_REMOTE" ]; then
  echo "Error: origin is $origin_url, expected $SOURCE_REMOTE." >&2
  exit 1
fi

# ① 先拉最新源码
echo "Pulling latest source..."
if [ -x "$SSH_WRAPPER" ]; then
  GIT_SSH_COMMAND="$SSH_WRAPPER" git pull --rebase --autostash origin main
else
  git pull --rebase --autostash origin main
fi

if [ -z "$(git status --short)" ]; then
  echo "No source changes."
  exit 0
fi

echo "Validating Hugo source..."
hugo --destination /tmp/hugo-build --cleanDestinationDir --minify --gc

rm -rf "$SITE_DIR/resources" "$SITE_DIR/.DS_Store"
if ! lsof -nP -iTCP:1313 -sTCP:LISTEN >/dev/null 2>&1; then
  rm -f "$SITE_DIR/.hugo_build.lock"
fi

echo "Backing up Hugo source to origin/main..."
git add -A

if [ -z "$(git diff --cached --name-only)" ]; then
  echo "No source changes after cleanup."
  exit 0
fi

git commit -m "$COMMIT_MESSAGE"

# ② SSH wrapper 推送
if [ -x "$SSH_WRAPPER" ]; then
  GIT_SSH_COMMAND="$SSH_WRAPPER" git push origin main
else
  git push origin main
fi

echo "Source backup completed."

四、配置 shell 快捷命令

把下面这段加到 ~/.bashrc（新机器人用 .bashrc；macOS 用 .zshrc）：

# ── Hugo publish & source backup ──
purodn() {
    /bin/sh "$HOME/codex/hugo/scripts/purodn" "$@"
}

purodncode() {
    /bin/sh "$HOME/codex/hugo/scripts/purodncode" "$@"
}

生效：

source ~/.bashrc

五、SSH wrapper（本机 OpenSSH 9.9 特殊处理）

背景：本 VPS 无 root（PID 1 systemd 以 nobody 运行），OpenSSH 9.9+ 对 /etc/ssh/ssh_config.d/20-systemd-ssh-proxy.conf 做权限检查，配置文件属主为 nobody:nogroup 导致 git 的 ssh 子进程报 fatal: unable to fork。所有 git 远程操作必须带 wrapper。

~/.hermes/scripts/git-ssh-wrapper.sh（无明文凭据，可安全入库）：

#!/bin/bash
# Git SSH wrapper - bypasses OpenSSH 9.9+ permissions check on
# /etc/ssh/ssh_config.d/20-systemd-ssh-proxy.conf (owned by nobody:nogroup)
HACK_SO="/home/hermesuser/.hermes/scripts/ssh_bypass_hack.so"
if [ -f "$HACK_SO" ]; then
    export LD_PRELOAD="$HACK_SO"
fi
exec /usr/bin/ssh "$@"

依赖的 ssh_bypass_hack.so 是一个 LD_PRELOAD 动态库（绕过上述权限检查），路径同目录。

新机器注意：如果新环境有 root 或 OpenSSH 配置正常，不需要 wrapper——脚本里的 if [ -x "$SSH_WRAPPER" ] 判断会自动降级为普通 git push，无需改脚本。

七、常见问题

症状 原因 解决
fatal: unable to fork 裸 git push 无 wrapper 确认 ~/.hermes/scripts/git-ssh-wrapper.sh 存在；手动 GIT_SSH_COMMAND=... git push
cannot pull with rebase: You have unstaged changes 缺 --autostash 脚本已带，手动操作时记得加
构建后 Error: draft tag still present 草稿 tag 页残留 按提示删 public/tags/<tag> 再跑
hugo command not found Hugo 未装 见第二节依赖
