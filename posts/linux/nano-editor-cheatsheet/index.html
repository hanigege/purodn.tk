nano 编辑器速查：快捷键、查找与替换

nano 常用快捷键速查表（光标移动、编辑、保存退出），以及查找、查找并替换的完整操作步骤，附实测验证。

nano 是 Linux / FreeBSD / Alpine 等系统里最轻量易用的终端文本编辑器，几乎所有发行版都默认自带，适合快速修改配置文件（/etc/nginx/nginx.conf、/etc/ssh/sshd_config 等）。本文整理常用快捷键速查表，以及查找、替换的完整操作流程。

💡 提示：文中的 Ctrl+X 表示按住 Ctrl 再按 X 键；Alt+U 表示按住 Alt（或 Esc）再按 U。快捷键以 GNU nano 8.x 实测为准，旧版本绑定基本一致。

一、常用快捷键速查表

1. 光标移动

快捷键功能
Ctrl+A跳到行首
Ctrl+E跳到行尾
Ctrl+Y上一屏（向上翻一页）
Ctrl+V下一屏（向下翻一页）
Alt+\（或 Ctrl+Shift+\）跳到文件第一行
Alt+/（或 Ctrl+Shift+/）跳到文件最后一行
Ctrl+/（终端里等同 Ctrl+_、Ctrl+Shift+-）跳转到指定行号，输入行号后回车
Ctrl+↑ / Ctrl+↓跳到上一个 / 下一个文本块
Alt+↑ / Alt+↓光标不动，屏幕向上 / 向下滚动一行

💡 跳到文件末尾的取巧方法：按 Ctrl+/，输入一个超大行号（如 9999），回车后 nano 会直接跳到文件最后一行——这就是很多教程里「Ctrl+Shift+- 然后输入 9999」的真实含义。

2. 编辑操作

快捷键功能
Ctrl+K剪切（删除）当前行；有标记区域时删除整个选区
Ctrl+U粘贴剪贴板内容
Alt+6复制当前行（或标记区域）
Alt+U撤销上一步操作
Alt+E重做（恢复被撤销的操作）
Alt+A（或 Ctrl+6）开始 / 结束标记文本（配合方向键扩展选区）
Ctrl+J对齐当前段落（自动换行）

⚠️ 注意：Ctrl+6 就是 Ctrl+Shift+6，在终端里和 Alt+A 是同一个「标记」功能；再按一次取消标记。

3. 文件操作

快捷键功能
Ctrl+O保存文件（回车确认）
Ctrl+X退出 nano（有未保存修改时会询问）
Ctrl+R插入另一个文件的内容
Ctrl+G打开内置帮助（所有快捷键一览）

4. 查找与替换

快捷键功能
Ctrl+F（旧版本/兼容绑定为 Ctrl+W）向前查找字符串
Ctrl+B向后查找字符串
Alt+F（或 Alt+W）查找下一个匹配（向前）
Alt+B查找上一个匹配（向后）
Ctrl+\查找并替换

5. 其他常用

快捷键功能
Ctrl+C显示光标当前所在的行号、列号
Ctrl+T执行外部命令
Ctrl+Space / Alt+Space向前 / 向后移动一个单词

二、查找文本

假设要编辑 Nginx 配置文件：

  1. 打开文件：
nano /etc/nginx/nginx.conf
  1. 按 Ctrl+F（或 Ctrl+W）进入查找模式，屏幕底部会出现：
Search:

  1. 输入要查找的内容（例如 server_name），按 Enter，光标会跳到第一个匹配处。

  2. 继续查找下一个匹配：再按一次 Ctrl+F，直接按 Enter 即可（nano 会记住上一次的关键词）。

三、查找并替换

  1. 按 Ctrl+\ 进入替换模式（注意是反斜杠 \，需在英文输入状态下输入），底部提示：
Search (to replace):
  1. 输入要查找的内容（例如 80），按 Enter，接着提示：
Replace with:

  1. 输入替换内容（例如 8080），按 Enter。

  2. 光标停在第一个匹配处，底部出现确认提示：

Replace this occurrence? (Yes/No/All/Cancel)
按键含义
Y（Yes）替换当前匹配，并跳到下一个
N（No）跳过当前匹配
A（All）替换全部匹配，不再逐个确认
Ctrl+C（Cancel）取消替换操作
  1. 替换完成后按 Ctrl+O 保存，Ctrl+X 退出。

四、小技巧

  • 先查再换：不确定文件中是否包含目标字符串时，先用 Ctrl+F 查一下确认，再决定要不要替换。
  • 全文删除：按 Alt+A 开始标记 → 按 Alt+/ 跳到文件末尾（相当于全选）→ 按 Ctrl+K 一次性删除全部内容。
  • 保存退出组合：Ctrl+O → Enter 保存，Ctrl+X 退出；修改重要系统配置前建议先 cp 备份一份。
  • 忘记快捷键：任何时候按 Ctrl+G 打开内置帮助，底部两行也会常驻显示最常用快捷键。

五、总结

nano 的核心操作可以压缩成一句话：Ctrl+O 保存、Ctrl+X 退出、Ctrl+F 查找、Ctrl+\ 替换、Ctrl+K 删行、Ctrl+U 粘贴。配合 Alt+U 撤销和 Alt+E 重做，足以完成绝大多数终端环境下的文本编辑任务。

✅ 实战验证：本文快捷键表在 GNU nano 8.3（Ubuntu 环境实测）下逐一核对自内置帮助（Ctrl+G），查找/替换/保存/退出流程与 Alpine Linux 自带 nano 一致。若系统 nano 版本较旧，Ctrl+W 仍可作为查找的兼容绑定使用。
